# 研究法・極限題庫

A browser-based Social Research Methods practice site, built from the uploaded course slides.

## Included units
- 抽樣的邏輯
- 實驗法
- 評估研究
- 量化評估／單案評估設計
- 推論統計回顧
- 問卷試測與分析
- 非介入性研究

## Features
- High-difficulty multiple-choice questions with instant answer explanations
- Long-answer prompts with self-check rubrics
- Topic filters and mixed-topic sets
- Generate another set and avoid recently seen questions until a pool cycles
- Print-friendly layout for PDF export
- No external API key or backend required

## Run locally
Open `index.html` in a modern browser.

## Publish
Enable GitHub Pages for the `main` branch and `/(root)` in repository Settings → Pages.
